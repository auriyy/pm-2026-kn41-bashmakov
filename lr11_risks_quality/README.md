## 3. Definition of Done

Файл `dod.md`, умов у списку: 6.

Definition of Done вимагає виконання критеріїв приймання, перевірки основного й негативного сценаріїв, самоперевірки за чеклістом, відсутності критичних дефектів і зафіксованого приймання результату.

Від вимоги обов'язкового code review другою людиною відмовився, оскільки навчальний проєкт ведеться одним основним виконавцем. Замість цього використовується перевірка за чеклістом та демонстрація результату.

Кількість завершених історій, які пройшли DoD, наведено в останніх розділах `dod.md`.

| Вимога | O | M | P | PERT | Оцінка |

Це зберігає заплановані дати, але створює ризик неприйняття релізу, якщо вимога є обов'язковою.

Якщо після погодження замовник вимагатиме включити 8 SP до REL-1, знадобиться оновити WBS, календар і прогноз або вилучити еквівалентний обсяг інших історій.
