## 1. Definition of Workflow

| Колонка | Коли картка входить | Коли картка виходить |
| --- | --- | --- |
| Backlog | Сформульовано завдання, очікуваний результат і створено картку | Уточнено обсяг і критерії готовності |
| Ready | Опис роботи зрозумілий і матеріали доступні | Виконавець бере роботу за наявності місця в WIP |
| In progress | Розпочато виконання, записано дату старту | Результат підготовлено до перевірки |
| Review | Є результат для перевірки | Критерії завершення прийняті або картку повернуто на виправлення |
| Done | Завдання прийнято, дату завершення зафіксовано | Завершені картки залишаються в Done |

Картки F-001–F-012 є завданнями з підготовки проєктних артефактів, а не продуктовими user stories. Для них використовується тип `other`.

Cycle time визначається як різниця календарних дат Done і початку In progress.

Інші термінові завдання потрібно обговорювати з відповідальною особою, визначаючи їхню пріоритетність і вплив на основний потік.

## 6. Перший вимір

Для вимірювання використано вісім завершених основних карток F-001–F-008.

Їхній cycle time:

1, 1, 1, 2, 2, 2, 2, 2 дні.

Середній cycle time:

(1 + 1 + 1 + 2 + 2 + 2 + 2 + 2) / 8 = 13 / 8 = 1,625 дня.

| Показник | Значення |
| --- | ---: |
| Мінімальний cycle time | 1 день |
| Максимальний cycle time | 2 дні |
| Середній cycle time | 1,625 дня |
| Завершено основних карток | 8 |

F-013 не включено до виміру восьми основних карток, але її дані збережено окремо.

Найдовше картки чекали в Ready через WIP-ліміт In progress = 1.

Старт F-006 додатково затримався через термінову F-013.
